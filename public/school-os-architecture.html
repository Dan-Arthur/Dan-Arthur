Environment
Configuration Notes
SQL Server Connection

TCP is disabled on the SQLDEV instance. Connection uses a named pipe configured directly in config/database.php (the DB_HOST .env value is unused for the host path — the PHP string literal is the source of truth to avoid backslash escaping issues in dotenv).

PHP Installation

XAMPP at C:\xampp\php\php.exe. SQL Server PHP driver v5.12.0 (TS x64) manually installed. Run artisan commands with the full path.

FK Cascade Policy

All foreign keys use NO ACTION (no cascade delete or set null). SQL Server's multiple-cascade-path restriction prevents cascades across the school → campus → child chain. Data cleanup is handled at the application layer via model observers and service classes.

Dev Server

C:\xampp\php\php.exe artisan serve --host=0.0.0.0 --port=8000
